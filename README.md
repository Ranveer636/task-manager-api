\# Task Management API



Minimal REST API built with Express and Mongoose to handle CRUD operations for task tracking. Includes title search and a tested Postman collection.



\## Tech Stack

\- Node.js

\- Express

\- MongoDB Atlas (Mongoose)



\## Environment Variables

Create a `.env` file in the root directory:

```env

PORT=5000

MONGO\_URI=your\_mongodb\_connection\_string
